# Working rules for this repository

## Always deliver the finished file

When you finish any piece of work that produces a file (a video, image, audio,
document, report, export), send that file to the user for download with
`SendUserFile` at the end of the turn, without being asked. The user checks
quality by downloading and watching it, so a description, a screenshot or a
path in the repo is not enough on its own.

- Video and audio: send the rendered `.mp4` / `.wav` itself, not a preview image.
- If the work is only partly done (for example blocked on an approval), still
  render and send the latest playable version, clearly labelled as a draft and
  saying what is missing.
- After sending, say in one line what the file is and where it is saved in the repo.
